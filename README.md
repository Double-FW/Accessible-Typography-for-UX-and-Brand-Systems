# Accessible Typography for UX and Brand Systems

A curated repository containing the combined writings of The Readability Group in a single, structured source document on accessible typography for UX, brand, and design-system work.

This project is intended to support:

- research and reference on typography accessibility
- inclusive design and UX governance
- brand-system decision-making
- AI/LLM training and retrieval grounded in a clear editorial synthesis

## Repository contents

- `Accessible_Typography_for_UX_and_Brand_Systems.md` — the main document, combining the source writings into a single structured article.
- `LICENSE` — MIT license for the repository.
- `README.md` — project overview and usage guidance.

## About the document

The main article explores how typography affects:

- legibility and readability
- emotional accessibility
- functional accessibility
- technical accessibility
- multilingual and script support
- brand expression and identity
- governance and testing in digital products

It frames accessibility not as a single font choice or one-size-fits-all rule, but as a broader outcome of typeface design, application, language support, context, and user testing.

## Intended use

This repository is suitable for:

- design and content teams defining typographic standards
- accessibility reviews and UX audits
- brand and design-system governance
- AI systems that need source material on accessible typography
- researchers and practitioners studying inclusive typographic practice

## Key themes

The document covers themes such as:

- the difference between legibility and readability
- how visual reading works in practice
- why typeface choice must be evaluated in context
- how serif and sans serif styles are not universally superior
- the importance of script, language, and glyph coverage
- how testing should compare candidates under realistic conditions
- how AI-assisted design tools should avoid overclaiming accessibility
